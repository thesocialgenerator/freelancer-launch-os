# Website Playbook

Version: 1.0

---

# Purpose

The Website Playbook helps freelancers present their expertise through a professional portfolio website that builds credibility and converts visitors into clients.

A website should clearly communicate who you help, what you do, and how potential clients can take the next step.

---

# Philosophy

A website is not an online brochure.

It is a conversion tool.

Every page should answer one question:

> **"Why should I hire this person?"**

Freelancer Launch OS should prioritize clarity, trust, and conversion over flashy design.

---

# Core Framework

Every portfolio website should include these sections.

## 1. Hero Section

Immediately communicate:

* Who you help
* What you do
* The outcome you deliver
* A clear call to action

Example:

Helping E-commerce Brands Increase Revenue Through Email Marketing Automation.

CTA:

Book a Discovery Call

---

## 2. About

Summarize:

* Professional background
* Specialization
* Industries served
* Why clients trust you

Keep it concise and client-focused.

---

## 3. Services

Present services as business solutions.

Each service should include:

* Problem solved
* Solution provided
* Expected outcome

Avoid listing software without context.

---

## 4. Case Studies

Show real work using the Portfolio Playbook structure:

* Challenge
* Solution
* Responsibilities
* Tools
* Business Impact

Prioritize quality over quantity.

---

## 5. Process

Explain how you work.

Recommended framework:

Discover

↓

Plan

↓

Build

↓

Test

↓

Launch

↓

Support

A clear process reduces uncertainty and builds confidence.

---

## 6. Testimonials

Include genuine testimonials when available.

If none exist, omit the section or use placeholders during development.

Never fabricate testimonials.

---

## 7. Contact

End every page with a clear call to action.

Examples:

* Book a Call
* Send a Message
* Start Your Project

Reduce friction by making it easy to contact you.

---

# Navigation

Keep navigation simple.

Recommended menu:

* Home
* About
* Services
* Portfolio
* Contact

Add a Resume page only if it supports the user's goals.

---

# Design Principles

The website should be:

* Clean
* Responsive
* Fast
* Accessible
* Easy to scan
* Mobile-friendly

Use consistent typography, spacing, and branding.

---

# SEO Fundamentals

Each website should include:

* Clear page titles
* Meta descriptions
* Heading hierarchy (H1–H3)
* Descriptive image alt text
* Relevant keywords used naturally

Focus on readability first, SEO second.

---

# Common Mistakes

Avoid:

* Cluttered layouts
* Long blocks of text
* Weak calls to action
* Stock-heavy visuals
* Slow-loading pages
* Confusing navigation
* Listing tools instead of services

---

# AI Rules

When generating websites, Freelancer Launch OS should:

* Reuse content from the Offer, Resume, Portfolio, and LinkedIn Playbooks.
* Recommend a logical page structure.
* Write conversion-focused copy.
* Suggest visuals where appropriate.
* Optimize for desktop and mobile.
* Never invent testimonials or case studies.

---

# Output Checklist

Every website should include:

* Hero section
* About section
* Services
* Case studies
* Process
* Contact section
* Clear navigation
* Calls to action
* Responsive layout recommendations
